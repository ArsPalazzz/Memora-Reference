# Gym text — grammar (past perfect, by + -ing, would be to…)

Текст про зал. Здесь — **грамматика**, из‑за которой путаница.  
Лексика: [[english/Words/Vocabulary notes/gym text phrases|gym text phrases]]

## 1. Past perfect → потом Present: почему нет «согласования»?

> I’d always **been** slightly scornful of people who ‘do exercise’ – **they’re** always so ready to tell you…

| Часть | Время | Зачем |
|---|---|---|
| **I’d always been scornful** | Past Perfect | состояние **до** истории: «всегда (до того) относился с презрением» |
| **they’re always so ready** | Present | **общая правда** про таких людей сейчас / вообще |

Это **не** reported speech и не одно «временное поле».  
Тире ≈ отдельный комментарий: «а они, знаешь, вечно всем рассказывают…».

```ad-example
title: Example
color: 78, 121, 237
- I'd never liked spicy food — **it's** just too hot for me. 🟢 _(факт вообще)_
- I'd never liked spicy food — **it was** just too hot. _(тоже ок, если всё в прошлом)_
```

**Когда так:** рассказ в прошлом + вставка «а люди / мир **такие**» → present.  
Не надо всё подряд сдвигать в past.

Связано: [[english/Rules/Tenses/The perfect aspect|The perfect aspect]] · [[english/Rules/Tenses/Tense agreement (when to backshift)|Когда согласовывать времена]]

## 2. started **by** + **-ing** (не with)

> I started **by** just **lifting** a few weights…

**by + -ing** = **способ / с чего начал** (метод).  
После предлога *by* — всегда **-ing**, не *to lift*.

```ad-example
title: Example
color: 78, 121, 237
- I started **by** reading the instructions.
- She began **by** introducing herself.
- I started **with** a coffee. _(with + noun: с чего / с чем в руках)_
```

| | |
|---|---|
| **start by + -ing** | начать **с действия** (метод) |
| **start with + noun** | начать **с вещи / пункта** |

Связано: [[english/Rules/Gerunds and infinitives/Infinitive vs gerund|Infinitive vs gerund]]

## 3. few vs a few

> lifting **a few** weights

| | Смысл | Тон |
|---|---|---|
| **a few** | несколько (есть, нормально) | нейтральный / + |
| **few** | мало (почти нет) | негативный |

```ad-example
title: Example
color: 78, 121, 237
- I lifted **a few** weights. _(несколько — ок)_
- **Few** people came. _(мало кто пришёл — жаль)_
```

Здесь **a few** = «пару / несколько».

Связано: [[english/Rules/Pronouns and determiners/much, many, a lot of, a little, a few|a few / a little]]

## 4. my advice **would be to** + V

> my advice to others **would be to** just make one change…

После *be* (и *would be*) часто **to + infinitive** = «совет — **сделать** X»:

```ad-example
title: Example
color: 78, 121, 237
- My advice **is to** wait.
- The best option **would be to** start small.
- What you need **is to** rest.
```

*Would* здесь мягче / вежливее, чем *is*.

---

## 5. …make one change **to start with**

**to start with** = идиома «**для начала**» (не «чтобы начать с» в буквальном смысле).  
Стоит в конце — нормально:

```ad-example
title: Example
color: 78, 121, 237
- Make one change **to start with**.
- **To start with**, make one change. _(то же, в начале)_
```

≈ *for a start* / *first of all*.

Связано: [[english/Words/For a start|for a start]]

## 6. enjoy wherever it **leads** you

**lead** = вести / приводить куда-то (результат пути).

> enjoy **wherever it leads you**  
> = наслаждайся **тем, куда это тебя приведёт** (куда бы ни)

```ad-example
title: Example
color: 78, 121, 237
- I don't know where this job will **lead**.
- One thing **led** to another.
- Follow your curiosity and see where it **leads** you.
```

Не путать с *lead* (свинец) и *led* (past от lead).

## Шпаргалка по грамматике текста

| Кусок | Правило |
|---|---|
| I’d always been… – they’re always… | past state + общий present-комментарий |
| started **by** lifting | by + **-ing** = метод |
| **a few** weights | несколько (+) |
| would be **to** make | be + **to**-infinitive |
| to start with | «для начала» (идиома) |
| wherever it **leads** you | lead = привести к результату |
