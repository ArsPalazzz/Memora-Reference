## Движение / начало

### head to

= направиться / поехать / пойти **куда-то**.

```ad-example
title: Example
color: 78, 121, 237
- I **headed to** the gym.
- Let's **head to** the café.
```

## Отношение / оценка

### slightly

= слегка / немного (смягчает прилагательное).

```ad-example
title: Example
color: 78, 121, 237
- **slightly** scornful / tired / better
```

### scornful of

= с презрением / свысока к кому-то / чему-то.

```ad-example
title: Example
color: 78, 121, 237
- I'd been **scornful of** people who ‘do exercise’.
- Don't be **scornful of** beginners.
```

## Темп / совет

### take it steady

= не торопись / спокойно / без фанатизма (UK).  
≈ *take it easy*, *go steady*.

```ad-example
title: Example
color: 78, 121, 237
- Definitely **take it steady**.
```

### take it one step at a time

= по одному шагу / не всё сразу.

```ad-example
title: Example
color: 78, 121, 237
- **Take it one step at a time.**
```

### start small

= начни с малого.

```ad-example
title: Example
color: 78, 121, 237
- **Take it steady** and **start small**.
```

## Польза / сферы жизни

### feel the benefits

= почувствовать **пользу / эффект**.

```ad-example
title: Example
color: 78, 121, 237
- I started to **feel the benefits** quite quickly.
```

### in terms of

= **с точки зрения** / что касается…

```ad-example
title: Example
color: 78, 121, 237
- not just **in terms of** fitness and energy
- expensive **in terms of** time
```

### filter into

= **просочиться / перейти** в другие области (влияние «разлилось»).

```ad-example
title: Example
color: 78, 121, 237
- how it **filtered into** other areas of my life
```

### positive spiral

= **позитивная спираль** (хорошее → ещё хорошее).  
Противоположность: *vicious circle / downward spiral*.

```ad-example
title: Example
color: 78, 121, 237
- It was like a **positive spiral** in my life.
```

## Люди / привычки

### catch up with

= встретиться / созвониться, **нагнать новости** (давно не виделись).

```ad-example
title: Example
color: 78, 121, 237
- **catch up with** old friends
- Let's **catch up** soon.
```

Также: *catch up with work* = нагнать работу.

### commit to

= **обязаться / всерьёз взяться** за что-то (держаться плана).

```ad-example
title: Example
color: 78, 121, 237
- you won't **commit to** things you don't enjoy
- I'm **committed to** training three times a week.
```

### stick to

= **придерживаться** (правил, целей, плана).

```ad-example
title: Example
color: 78, 121, 237
- set yourself some goals and **stick to** them
```

### get out of that rut

**rut** = колея / застой.  
**get out of a rut** = выбраться из рутины / «застоявшейся» жизни.

```ad-example
title: Example
color: 78, 121, 237
- **Get out of that rut.**
```
