# dedicated / purely · dedicated to (not for)

Фраза: **It's a tattoo dedicated purely to you.**  
= «Это тату, посвящённое **только тебе** / исключительно тебе».

---

## 1. dedicated to…

**be dedicated to** + кто / что = **посвящён** кому-то / чему-то  
(книга, песня, тату, фильм, жизнь, работа…)

```ad-example
title: Example
color: 78, 121, 237
- This song is **dedicated to** my mum.
- A tattoo **dedicated to** you.
- She's **dedicated to** her work. _(преданa работе)_
```

### Почему **to**, а не **for**?

Стабильная связка: **dedicate something to someone**.  
Как *give to*, *send to* — кому адресовано / кому посвящено → **to**.

| ✅ | ❌ / редко |
|---|---|
| dedicated **to** you | dedicated **for** you |
| a book dedicated **to** his wife | |

*for* иногда встречается в другом смысле («предназначен для использования»), но не в «посвятить человеку»:

```ad-example
title: Example
color: 78, 121, 237
- a room **dedicated to** storage ≈ помещение под склад _(цель)_
- a tattoo dedicated **to** you = **тебе** посвящено _(человеку)_
```

В твоей фразе человек = адресат посвящения → только **to**.

---

## 2. purely

**purely** = **только / исключительно / чисто** (ничего другого).  
Усиливает: не «в том числе тебе», а **именно и только** тебе.

```ad-example
title: Example
color: 78, 121, 237
- dedicated **purely to** you = dedicated **only** to you
- It's **purely** for fun. _(чисто ради веселья)_
- I asked **purely** out of curiosity.
```

Близко: *only, exclusively, simply, just* (не всегда взаимозаменяемы по тону).

---

## 3. Фраза целиком

> It's a tattoo **dedicated purely to** you.

| Кусок | Роль |
|---|---|
| **dedicated … to you** | посвящено тебе |
| **purely** | исключительно, никому больше |

Оттенок: романтично / сильно; «это про тебя одного».

Другие варианты того же смысла:

```ad-example
title: Example
color: 78, 121, 237
- a tattoo **dedicated only to** you
- a tattoo **just for** you _(for тут ок: «для тебя» как подарок/предназначение)_
- This tattoo is **for** you. _(проще: тебе / для тебя)_
```

**for you** = «для тебя» (предназначение).  
**dedicated to you** = «посвящено тебе» (формальнее / сильнее по смыслу «в честь тебя»).

---

## 4. Когда юзать в речи

### dedicated

| Контекст | Пример |
|---|---|
| посвятить работу человеку | This book is **dedicated to** my parents. |
| преданный делу | He's **dedicated to** helping kids. |
| специальный / отдельный | a **dedicated** support team _(отдельная команда)_ |

### purely

| Контекст | Пример |
|---|---|
| только одна причина | It was **purely** accidental. |
| исключить другие мотивы | I'm asking **purely** as a friend. |
| усилить «только» | **purely** personal / **purely** professional |

---

## Шпаргалка

- **dedicated to** + человек/дело — не *for*  
- **purely** = exclusively / only  
- *dedicated purely to you* = посвящено **исключительно** тебе  
- *a tattoo for you* — проще; *dedicated to you* — «посвящение»
