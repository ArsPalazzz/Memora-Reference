# This vs it

**this** — указываем на то, что **рядом** / представляем человека.  
**it** — говорим **снова** о уже названном (вещь, животное, ситуация) или о времени / погоде / расстоянии; также в структуре **It's + adj…**.

## 1. This — рядом с тобой

Как будто указываешь пальцем на то, что перед тобой:

```ad-example
title: Example
color: 78, 121, 237
- **This** cat is cute. _(кот рядом)_
- **This** is my house. _(дом перед тобой)_
- I think **this** jacket is perfect for you.
```

### Представление

Знакомим человека или представляемся по телефону:

```ad-example
title: Example
color: 78, 121, 237
- **This** is my brother John.
- Hello, **this** is Linda. _(по телефону)_
```

### Множественное число — these

```ad-example
title: Example
color: 78, 121, 237
- **These** are my brothers, John and Edward.
```

---

## 2. It — снова о том же

Местоимение (как *he / she*), но для **предметов и животных** — когда уже упомянули:

```ad-example
title: Example
color: 78, 121, 237
- This cat is cute. **It** is sleeping.
- This is my house. I bought **it** last year.
```

Также для **ситуации / идеи**, о которой уже говорили:

```ad-example
title: Example
color: 78, 121, 237
- There was a storm, and they cancelled the concert. **It** was a disaster. _(шторм + отмена)_
```

---

## 3. It — время, дата, погода, расстояние

```ad-example
title: Example
color: 78, 121, 237
- **It's** very late.
- 'What day is **it**?' '**It's** Tuesday.'
- **It** was sunny yesterday.
- **It's** not very far from here.
```

---

## 4. It's + adjective + to-infinitive

```ad-example
title: Example
color: 78, 121, 237
- **It's** nice **to see** you again.
- **It's** easy **to get** lost in this part of the city.
```

---

## 5. It's + adjective + that…

```ad-example
title: Example
color: 78, 121, 237
- **It's** important **that** you learn this.
```

---

## Шпаргалка

| | Когда | Пример |
|---|---|---|
| **this** | рядом / указываем; представление | This cat is cute. This is Linda. |
| **these** | мн. ч. от this | These are my brothers. |
| **it** | снова о вещи / животном / ситуации | I bought **it** last year. |
| **it** | время, дата, погода, расстояние | It's Tuesday. It was sunny. |
| **It's + adj + to…** | оценка действия | It's nice to see you. |
| **It's + adj + that…** | оценка факта | It's important that you learn this. |
