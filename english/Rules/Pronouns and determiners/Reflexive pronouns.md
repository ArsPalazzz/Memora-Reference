# Reflexive pronouns (myself, yourself…)

Когда **подлежащее** и **дополнение** — **один и тот же человек**, вместо *me / him / her…* ставят **reflexive**: *myself / himself…*

Репетитор: *…to **me*** → *…to **myself*** — потому что делаешь это **себе** (I … to myself).

---

## Формы

| Subject | Object | **Reflexive** |
|---|---|---|
| I | me | **myself** |
| you | you | **yourself** |
| he | him | **himself** |
| she | her | **herself** |
| it | it | **itself** |
| we | us | **ourselves** |
| you (мн.) | you | **yourselves** |
| they | them | **themselves** |

---

## 1. Главное правило

**Subject = object** → reflexive.

```ad-example
title: Example
color: 78, 121, 237
- I cut **me**. 🔴
- I cut **myself**. 🟢 _(я порезал **себя**)_
- She bought a gift for **her**. 🔴 _(если про ту же she)_
- She bought a gift for **herself**. 🟢
- He talked to **him**. _(другому мужчине)_
- He talked to **himself**. _(сам с собой)_
```

Твой случай:

> I would give **it** to **myself** and go away.

- **I** = кто даёт  
- **myself** = кому (тому же человеку)  
→ не *to me*

---

## 2. Когда НЕ reflexive

Если объект — **другой** человек / вещь:

```ad-example
title: Example
color: 78, 121, 237
- I gave the money to **him**. 🟢 _(не себе)_
- Can you help **me**? 🟢 _(you ≠ me)_
- She saw **him** at the party. 🟢
```

---

## 3. Частые глаголы + reflexive

| | Пример |
|---|---|
| hurt / cut / burn | I **hurt myself**. |
| enjoy | Did you **enjoy yourself**? |
| introduce | Let me **introduce myself**. |
| blame | Don't **blame yourself**. |
| teach | She **taught herself** Spanish. |
| look after | You should **look after yourself**. |

---

## 4. Для усиления (не объект)

Иногда *myself* = «сам / лично» — подчёркивание, не «себе»:

```ad-example
title: Example
color: 78, 121, 237
- I **myself** don't believe it. _(я лично)_
- She fixed it **herself**. _(сама, без помощи)_
- I'll do it **myself**.
```

В твоей фразе репетитор имела в виду именно **дополнение себе**, не усиление.

---

## 5. Ещё правка: them → it

> money is a **singular** noun → **it**, не *them*

```ad-example
title: Example
color: 78, 121, 237
- I would give **them** the money… 🔴 _(them ≠ money)_
- I would give **it** to myself… 🟢 _(it = money)_
```

*them* = люди / мн. ч.; *money* → **it**.

---

## Шпаргалка

| | |
|---|---|
| один и тот же человек | **myself / yourself / himself…** |
| другой человек | **me / you / him…** |
| money / advice / information | обычно **it** (не them) |
| усиление «сам» | I'll do it **myself** |
