# Much, many, a lot of, a little, a few, no, any, none

Количество: **много / мало / ноль**. Выбор зависит от **countable / uncountable** и от типа предложения (**+ / − / ?**).

![[much many a lot little few.png]]

---

## 1. Much / many

**many** + countable (мн. ч.), **much** + uncountable.  
Обычно в **отрицаниях** и **вопросах**, не в утверждениях:

```ad-example
title: Example
color: 78, 121, 237
- There isn't **much** coffee in the jar.
- Were there **many** people at the party?
```

---

## 2. How much / how many

Спрашиваем про количество: **how many** + мн. ч., **how much** + uncountable:

```ad-example
title: Example
color: 78, 121, 237
- **How many** books did you read last semester?
- **How much** coffee do you drink every day?
```

Также **How much…?** = сколько **стоит**:

```ad-example
title: Example
color: 78, 121, 237
- '**How much** is it?' 'It's 43 pounds.'
- '**How much** are the trousers?' 'They're 58 pounds.'
```

---

## 3. A lot (of)

**a lot of** — и с countable, и с uncountable; обычно в **утверждениях** (большое количество):

```ad-example
title: Example
color: 78, 121, 237
- She spends **a lot of** time watching TV.
- We had **lots of** good moments together.
```

**quite a lot of** — «довольно много» (среднее количество):

```ad-example
title: Example
color: 78, 121, 237
- With my new job, I have **quite a lot of** free time.
```

Можно и в **− / ?**:

```ad-example
title: Example
color: 78, 121, 237
- Do you eat **a lot of** sugar?
- I don't read **a lot of** books.
```

### of перед существительным; без of в конце

Перед noun — всегда **a lot of**. В конце предложения / в коротком ответе — **a lot** (без *of*):

```ad-example
title: Example
color: 78, 121, 237
- 'How many beers did you have?' 'I don't know; I had **a lot**.'
- I like her **a lot**.
- 'How much coffee did you have?' '**A lot**.'
```

---

## 4. A few / a little

**a few** + countable (мн. ч.), **a little** + uncountable — небольшое количество (в **+ / − / ?**):

```ad-example
title: Example
color: 78, 121, 237
- I have to do **a few** things this afternoon.
- I always put **a little** milk in my tea.
```

### not many / not much

Смысл похож: **not many** + мн. ч., **not much** + uncountable:

```ad-example
title: Example
color: 78, 121, 237
- I don't have to do **many** things this afternoon.
- I don't put **much** milk in my tea.
```

---

## 5. No / not…any / none

Ноль: **no + noun** = **not…any + noun**:

```ad-example
title: Example
color: 78, 121, 237
- I have **no** time today. = I don't have **any** time today.
```

В коротких ответах — **none** (без существительного):

```ad-example
title: Example
color: 78, 121, 237
- 'How much time do you have?' '**None**.'
```

---

## Шпаргалка

| | Countable | Uncountable | Оба |
|---|---|---|---|
| **Много** (− / ?) | **many** | **much** | **a lot of** (+ чаще) |
| **Мало** | **(a) few** | **(a) little** / a bit of | |
| **Ноль** | **no** / **not…any** (+ noun); **none** (без noun) | | |

| Форма | Когда |
|---|---|
| **a lot of** + noun | перед существительным |
| **a lot** | конец предложения / короткий ответ |
| **How much…?** | количество uncountable **или** цена |
