# Inversion (negative adverbials)

SpeakOut 6A — **inversion**: отрицательное / ограничивающее наречие в **начале** → меняем местами **auxiliary + subject** (как в вопросе). Для **эмфазы**, чаще в **формальном** языке.

![[Inversion 6A.png]]

**Исходная страница:** [[english/Rules/Course notes/SpeakOut/Inversion 6A|SpeakOut 6A]]  
Подробнее (B2): [[english/Rules/Inversion and emphasis/Inversion with negative adverbials|Inversion with negative adverbials]]

---

## Главная идея

Обычно: subject + verb  
С инверсией: **Never / Only later / Under no circumstances…** + **aux + subject** (+ verb)

```ad-example
title: Example
color: 78, 121, 237
- I have never seen such a wonderful sight!
- **Never have I seen** such a wonderful sight!
```

Триггеры в начале предложения: *never (before)*, *under no circumstances*, *not only… but also…*, *only* + время, *in no way*…

---

## 1. Есть auxiliary / modal → просто меняем местами

*have, will, can, should, was…*

```ad-example
title: Example
color: 78, 121, 237
- I had never been so scared before.
  → **Never before had I been** so scared!
- You should not give your bank details to anyone under any circumstances.
  → **Under no circumstances should you give** your bank details to anyone.
- He was not only handsome, but also rich.
  → **Not only was he** handsome, **but** he was **also** rich.
- It was only clear to me later that he had been lying.
  → **Only later was it** clear to me that he had been lying.
- I was not happy with the decision in any way.
  → **In no way was I** happy with the decision.
- I will never go there again.
  → **Never will I go** there again!
- She can't complain about the decision in any way.
  → **In no way can she** complain about the decision.
```

---

## 2. Нет auxiliary → добавляем do / does / did

Как в вопросах present/past simple:

```ad-example
title: Example
color: 78, 121, 237
- They only met the landlord three months later.
  → Only three months later **did they meet** the landlord.
- She not only plays the piano, but she also sings.
  → **Not only does she play** the piano, but she also sings.
```

---

## 3. Схема

| Шаг | |
|---|---|
| 1 | Отрицательное / restrictive наречие **в начало** |
| 2 | Есть have/will/can/was… → **aux + subject** |
| 3 | Нет aux → **do/does/did + subject + V** |

```
Never / Under no circumstances / Not only / Only later / In no way
+ auxiliary/modal (или do/did)
+ subject
+ …
```

---

## Шпаргалка

| Обычно | Инверсия |
|---|---|
| I have never… | **Never have I…** |
| You should never… under any circumstances | **Under no circumstances should you…** |
| He was not only… | **Not only was he…** |
| It was only clear later… | **Only later was it…** |
| They only met… later | Only later **did they meet…** |
