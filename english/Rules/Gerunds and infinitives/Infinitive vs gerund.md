# Infinitive vs gerund (verb patterns)

Когда после глагола / в роли подлежащего / после предлога — **-ing**, **to + V**, или **bare infinitive** (без *to*).

![[infinitive vs gerund.png]]

---

## 1. Gerund (-ing)

### Подлежащее

```ad-example
title: Example
color: 78, 121, 237
- **Reading** on tablets and phones isn't very good for your eyes.
- **Cheating** is not allowed.
```

### После предлога

```ad-example
title: Example
color: 78, 121, 237
- I'm tired **of waiting**. Let's go home.
- He's very good **at painting**.
```

### После некоторых глаголов

```ad-example
title: Example
color: 78, 121, 237
- I don't mind **waiting**.
- She recommended **visiting** this museum.
```

Частые глаголы + **-ing**: *avoid, enjoy, finish, hate, keep, like, love, (don't) mind, prefer, recommend, spend time, stop, suggest*…

### Отрицание: not + -ing

```ad-example
title: Example
color: 78, 121, 237
- He enjoys **not having** to wake up early at weekends.
- I love **not having** to go to work.
```

## 2. Bare infinitive (без to)

### После do / does / did (− / ?)

```ad-example
title: Example
color: 78, 121, 237
- He **didn't say** anything.
- **Does** Tim **work** with you?
- I **don't believe** you.
```

### После модальных (will, can, must, should…)

```ad-example
title: Example
color: 78, 121, 237
- You **should come** with us.
- I **can't play** the guitar.
```

---

## 3. to + infinitive

### После прилагательных

```ad-example
title: Example
color: 78, 121, 237
- It's important **to arrive** early at the station.
- I'm glad **to see** you.
```

### Цель / причина (why?)

```ad-example
title: Example
color: 78, 121, 237
- I went to Madrid **to visit** some family.
- I need time **to study** for the exam.
```

### После question words (what / where / how…)

```ad-example
title: Example
color: 78, 121, 237
- I don't know **what to eat**.
- I want to learn **how to play** the guitar.
```

### После некоторых глаголов

```ad-example
title: Example
color: 78, 121, 237
- Don't forget **to call** me.
- She seems **to be** distracted.
```

Частые глаголы + **to + V**: *ask (someone), decide, forget, help, hope, learn, need, offer, plan, promise, remember, seem, try, want, would like, would love, would hate, would prefer*…

### Отрицание: not to + V

```ad-example
title: Example
color: 78, 121, 237
- She decided **not to enter** the competition.
- I promise **not to lie** again.
```

---

## Шпаргалка

| Форма | Когда |
|---|---|
| **-ing** | подлежащее; после предлога; после *enjoy / mind / suggest…* |
| **bare infinitive** | после *do/does/did*; после модальных |
| **to + V** | цель; после adj; после *what/how…*; после *want / decide / seem…* |
| **not + -ing** | отрицательный gerund |
| **not to + V** | отрицательный to-infinitive |
