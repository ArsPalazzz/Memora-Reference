# The continuous aspect

SpeakOut 4B — **continuous aspect**: все формы **be + -ing** и когда их использовать.

![[The continuous aspect 4B.png]]

---

## Три аспекта в английском

| Аспект | На что акцент | Пример |
|---|---|---|
| **Simple** | действие **завершено** / факт | We **visited** Dublin last week. |
| **Perfect** | завершено **до** другого действия | Tom **had already left**. |
| **Continuous** | **процесс**, длительность — не результат | I'm **working** at the moment. |

**Continuous** = фокус на **самом действии** и том, **как долго** оно идёт, а не на том, что оно уже сделано.

---

## Форма

Все continuous = **форма be** + **-ing**

```
am/is/are + V-ing
was/were + V-ing
have/has been + V-ing
had been + V-ing
will be + V-ing
will have been + V-ing
```

---

## Все continuous формы

| Время | Формула | Пример |
|---|---|---|
| **Present continuous** | am/is/are + -ing | I'm **working** at the moment. |
| | | Where **are** you **living** now? |
| **Past continuous** | was/were + -ing | It **was raining** hard. |
| | | What **were** they **doing**? |
| **Present perfect continuous** | have/has been + -ing | He**'s been sitting** there all afternoon. |
| | | **Have** you **been waiting** long? |
| **Past perfect continuous** | had been + -ing | I could see she **had been crying**. |
| | | We **hadn't been expecting** visitors. |
| **Future continuous** | will be + -ing | I**'ll be seeing** Jack tomorrow. |
| | | Where **will** you **be staying**? |
| **Future perfect continuous** | will have been + -ing | By next month, I**'ll have been working** here for three years. |

| **Continuous infinitive** | to be + -ing | My phone seems **to be working** now. |

## Когда использовать continuous

### 1. Действие в процессе в конкретный момент

> She**'s working** at the moment.  
> He **was watching** TV when we arrived.

_Сейчас / тогда **в этот момент** что-то происходило._

### 2. Временная ситуация (не навсегда)

> I**'m staying** with friends at the moment.  
> We **were living** in Rome at that time.

_Временно — не постоянный факт._

| Continuous | Simple |
|---|---|
| I'm **living** with friends. (сейчас, временно) | I **live** in London. (постоянно) |

### 3. Ситуация **меняется**

> My French **is getting** better.  
> The weather **was getting** colder.

_Процесс изменения — continuous подчёркивает динамику._

### 4. Действие **длится период времени**

> I**'ve been studying** all afternoon.

_Весь день занимался — акцент на длительности._

→ Сравнение PPC vs Past Continuous: [[english/Rules/Tenses/Present Perfect Continuous vs Past Continuous|Present Perfect Continuous vs Past Continuous]]

## Continuous vs Simple — контраст

**Simple** — для:
- **фактов**
- **постоянных** ситуаций
- **завершённых** действий
- **привычек**

> I **visited** my brother in New York last year.  
> He **works** for a bank and **goes** to the gym every day.

**Continuous** — для:
- **процесса** прямо сейчас / тогда
- **временного**
- **изменения**
- **длительности**

> He **is working** on a project this week. (временно)  
> He **works** for a bank. (постоянная работа)

---

## State verbs — исключение

Некоторые глаголы **не** ставят в continuous — описывают **состояние**, не действие.

| ❌ Continuous | ✅ Simple |
|---|---|
| I'm not **understanding** | I **don't understand** |
| I've always been **loving** this | I've always **loved** this |

**Частые state verbs:** *know, believe, understand, love, hate, want, need, seem, belong, own, remember*

> I **don't understand** what you're saying.  
> I**'ve always loved** this restaurant!

**Но:** некоторые глаголы меняют смысл:
- I **think** it's good. (мнение) vs I'm **thinking** about it. (процесс размышления)
- She **has** a baby. (обладает) vs She's **having** a baby. (рожает)

| Акцент? | **процесс**, длительность |

| Тогда в процессе? | Past continuous |
| Длится с прошлого? | Present perfect continuous |
