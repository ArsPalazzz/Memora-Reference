# Stative (non-action) verbs

**Stative verbs** описывают **состояние**, не действие → обычно **simple / perfect**, **не continuous**.

![[stative or non-action verbs.png]]

См. также: [[english/Rules/Tenses/The continuous aspect|The continuous aspect]] (исключение state verbs)

---

## 1. Главное правило

```ad-example
title: Example
color: 78, 121, 237
- I **want** to eat. 🟢
- I **am wanting** to eat. 🔴
- He **looked** happy. 🟢
- He **was looking** happy. 🔴 _(здесь look = appear)_
```

---

## 2. Группы stative verbs

### Possession and size

*belong, own, have (= possess), possess, weigh, measure…*

```ad-example
title: Example
color: 78, 121, 237
- Ali **owns** three cars. 🟢
- Ali **is owning** three cars. 🔴
```

### Opinion

*know, believe, agree, think (= believe), imagine, understand…*

```ad-example
title: Example
color: 78, 121, 237
- I **know** what the answer is. 🟢
- I **am knowing** what the answer is. 🔴
```

### Likes, feelings, emotions

*like, love, want, need, wish, prefer, dislike…*

```ad-example
title: Example
color: 78, 121, 237
- Sam **likes** vegetables. 🟢
- Sam **is liking** vegetables. 🔴
```

### Perception and the senses

*sound, hear, seem, see\*, appear\*, look\*, taste\*, smell\*, feel\**

```ad-example
title: Example
color: 78, 121, 237
- You **sound** sad. 🟢
- You **are sounding** sad. 🔴
```

\* Обычно stative; как **voluntary action** могут быть dynamic (см. ниже).

---

## 3. Dynamic verbs

Действие / процесс → **любые** времена, в т.ч. continuous для «сейчас в процессе»:

```ad-example
title: Example
color: 78, 121, 237
- I **am eating** breakfast now. _(in progress)_
- I **eat** breakfast at the same time each day. _(habit)_
```

Частые dynamic: *eat, run, speak, walk, cook, watch, buy, drive…* (+ *smell / taste / feel / look*, когда это действие).

---

## 4. И stative, и dynamic

### have

```ad-example
title: Example
color: 78, 121, 237
- I **have** two cats. _(possess → stative)_
- They **are having** a party on Saturday. _(action)_
- I **was having** dinner when someone knocked. _(action)_
```

### be

```ad-example
title: Example
color: 78, 121, 237
- James **is** a doctor. _(state)_
- He **is being** very kind to us. _(behave → action)_
```

### think

```ad-example
title: Example
color: 78, 121, 237
- I **think** it is a good idea. _(opinion → stative)_
- Sara **is thinking** about her boyfriend. _(reflect → action)_
```

### look

```ad-example
title: Example
color: 78, 121, 237
- Tom **looks** like his sister. _(appear → stative)_
- Peter **is looking** out the window. _(focus eyes → action)_
```

### taste / see / smell / feel

Восприятие = stative; намеренное действие = dynamic:

```ad-example
title: Example
color: 78, 121, 237
- This soup **tastes** horrible. _(perception)_
- I **am tasting** the soup. _(checking the flavour)_
- I **saw** a man looking through a window. _(not voluntary)_
- Tom **is seeing** Katie this afternoon. _(meet / visit)_
```

## Шпаргалка

| Тип | Continuous? | Примеры |
|---|---|---|
| **stative** | обычно нет | know, want, own, seem |
| **dynamic** | да | eat, run, watch |
| **оба** | зависит от смысла | have, be, think, look, taste, see |
