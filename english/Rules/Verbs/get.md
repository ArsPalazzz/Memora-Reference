# Different uses of get

**get** + noun / adjective / **get to** + place — разные значения: получить, стать, добраться.

![[different uses of get.png]]

---

## 1. Get + noun

≈ *receive / obtain / buy / bring / take*:

```ad-example
title: Example
color: 78, 121, 237
- We **get** lots of **emails** every day. _(receive)_
- My son **got** his **driving license** last week. _(obtain)_
- Did you **get** a **present** for Tommy's birthday? _(buy)_
- 'How did you go to Pam's house?' 'I **got** a **train**.' _(take)_
```

---

## 2. Get + adjective

≈ *start to be* (становиться / начать быть):

```ad-example
title: Example
color: 78, 121, 237
- Why did you **get angry**?
- It's **getting dark**.
- When did they **get married**?
- After breakfast, I have a shower and **get dressed**.
```

---

## 3. Get to + place (= arrive)

```ad-example
title: Example
color: 78, 121, 237
- What time did you **get to** the hospital?
- She **gets to** work at 8.
```

**Без to:** *home / here / there*:

```ad-example
title: Example
color: 78, 121, 237
- Do you usually **get home** late? 🟢 _(не get **to** home)_
- It was difficult to **get here**. 🟢
- It was difficult to **get to here**. 🔴
```

---

## Шпаргалка

| Конструкция | Значение | Пример |
|---|---|---|
| **get** + noun | получить / купить / взять… | get an email, get the train |
| **get** + adjective | стать / начать быть | get tired, get married |
| **get to** + place | прибыть | get to work |
| **get** home / here / there | прибыть | **без** *to* |
