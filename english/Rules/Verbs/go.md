# How to use go

Разные конструкции с **go**: *go + -ing*, *go to*, *go to a/the*, *go for a*, *go on a*.

![[how to use go.png]]

---

## 1. Go (без to)

Направления вроде *home / downtown / there / somewhere / north* — обычно **без** *to*:

```ad-example
title: Example
color: 78, 121, 237
- go **home**, go **downtown**, go **there**, go **somewhere**, go **north**
```

---

## 2. Go + -ing

Спорт и занятия (*shopping, dancing, clubbing…*):

```ad-example
title: Example
color: 78, 121, 237
- I want to **go shopping** this afternoon.
- We **went kayaking** on Lake Michigan.
```

---

## 3. Go to (без the)

### work / bed

Без **the**:

```ad-example
title: Example
color: 78, 121, 237
- What time do you **go to work**?
- I'm tired. I'm **going to bed**.
```

### school / university

Без **the** = ходить туда **как ученик / студент**:

```ad-example
title: Example
color: 78, 121, 237
- They couldn't **go to school** for a few days because of the snow.
- Almost 40% of young people **go to university**.
```

### prison

Без **the** = попасть туда **как заключённый**:

```ad-example
title: Example
color: 78, 121, 237
- He could **go to prison** if the judge finds him guilty.
```

---

## 4. Go to a / the

**go to a/the** + место или событие. **the** — типичные места в городе (*bank, dentist, cinema…*):

```ad-example
title: Example
color: 78, 121, 237
- I need to **go to the dentist**.
- I'm **going to the bank**.
- **go to a** restaurant / party / wedding…
```

(*a* vs *the* — как обычно с артиклями.)

---

## 5. Go for a

**go for a** + существительное-занятие (*swim, run, walk, ride, drink…*):

```ad-example
title: Example
color: 78, 121, 237
- The weather is great today. I'm going to **go for a swim**.
- I have a new bike. Would you like to **go for a ride** with me?
```

---

## 6. Go on a

**go on (a)** + поездка / отдых (*holiday, trip, journey, excursion, tour, cruise…*):

```ad-example
title: Example
color: 78, 121, 237
- He **went on a cruise** with his family.
- Let's **go on an excursion** to explore the area.
```

---

## Шпаргалка

| Конструкция | Когда | Примеры |
|---|---|---|
| **go** + … | home, there, downtown… | go home |
| **go** + **-ing** | спорт / shopping и т.п. | go swimming, go shopping |
| **go to** (без the) | work, bed, school, university, prison | go to work |
| **go to a/the** | место / событие | go to the bank, go to a party |
| **go for a** | активность-noun | go for a walk |
| **go on a** | поездка / holiday | go on a trip, go on holiday |
