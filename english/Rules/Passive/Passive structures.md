# Passive structures

SpeakOut 6B — пассив, когда важен **результат / действие**, а не кто сделал. Плюс формы: **to be + V3**, **having been + V3**, **being + V3**.

**Исходная страница:** [[english/Rules/Course notes/SpeakOut/Passive structures 6B|SpeakOut 6B]]

---

## 1. Когда пассив

Фокус на **действии**, не на агенте:

| Зачем | Пример |
|---|---|
| агент **неизвестен** | It **was delivered** yesterday. |
| агент **и так понятен** | The man **was arrested** yesterday. |
| «люди вообще» | English **is spoken** around the world. |
| тот же subject | They ordered six chairs but only five **were sent**. |
| не винить / не признаваться | He broke a glass. → A glass **was broken**. |
| формально / объективно | часто в отчётах, новостях |

---

## 2. Passive infinitive — (to) be + V3

После модальных и *need / want / hope…*  
После модальных (*may, might, will, could…*) — **без** *to*:

```ad-example
title: Example
color: 78, 121, 237
- You **could be given** a promotion this year.
- I want the meeting **to be finished** as soon as possible.
- **To be sent** shoes for a child when you're an adult is annoying!
```

---

## 3. Perfect infinitive (passive) — (to) have been + V3

Про **прошлое** или уже завершённое:

```ad-example
title: Example
color: 78, 121, 237
- I **might have been sent** the wrong item.
- My birthday seems **to have been forgotten** by my brother.
```

Связано: [[english/Rules/Modal verbs/Modal verbs + Perfect Infinitive|Modal verbs + Perfect Infinitive]]

---

## 4. Passive -ing — being + V3

После глаголов с gerund (*avoid, keep, enjoy…*), после предлогов, как подлежащее:

```ad-example
title: Example
color: 78, 121, 237
- I avoid **being tagged** in photos online.
- I'm really looking forward to **being taken** on a tour of the building.
- **Being given** an end-of-year bonus was unexpected but welcome.
```

---

## 5. Perfect gerund (passive) — having been + V3

Про прошлое после *mind, resent…* / после предлога:

```ad-example
title: Example
color: 78, 121, 237
- We don't mind **having been missed** off the list once, but not twice!
- I resent **having been ignored** for much of the meeting.
- After **having been promised** a pay rise, I was disappointed not to get one.
```

---

## 6. Participle clause — Having been + V3

Обстоятельство «после того как / так как…» в прошлом:

```ad-example
title: Example
color: 78, 121, 237
- **Having been awarded** a prize for her work, Sally was delighted.
- **Having been born** in Australia, I've got an Australian passport.
```

Связано: [[english/Rules/Clauses/Participle clauses|Participle clauses]]

## Шпаргалка

| Форма | Структура | Когда |
|---|---|---|
| passive infinitive | **(to) be + V3** | после modal / want / need… |
| perfect passive infinitive | **(to) have been + V3** | прошлое / завершённое |
| passive -ing | **being + V3** | после gerund-глаголов / предлогов |
| perfect passive gerund | **having been + V3** | прошлое + -ing-контекст |
| participle | **Having been + V3,** … | обстоятельство в прошлом |

```
be + V3              → пассив «сейчас / вообще»
have been + V3       → пассив про прошлое (infinitive)
being + V3           → пассив-gerund
having been + V3     → пассив-gerund / participle про прошлое
```
