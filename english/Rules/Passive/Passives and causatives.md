# Passives and causatives

Когда пассив; **impersonal passive**; два объекта; когда пассив **избегают**; **causatives** (*get/have something done*…).

## 1. The passive — когда

| Зачем | Пример |
|---|---|
| **не знаем** кто | The car **was stolen** at approximately 1.30 am. |
| **очевидно** кто | **Having been introduced** in 1988, the Road Traffic Act… |
| **неважно** кто | The XL500 **was designed** with young families in mind. |
| **новая информация** в конце | This submarine **was developed** … **by the Americans**. |
| не начинать с **длинного** subject | We **were surprised** by the number of people trying to leave… |
| **формальный** стиль | All passengers **are required** to present their ticket. |

## 2. Impersonal passive

«Говорят / считают, что…» — три схемы:

### A) Noun + passive + infinitive / perfect infinitive

Глаголы: *agree, assume, believe, claim, consider, expect, know, report, say, suppose, think, understand…*

```ad-example
title: Example
color: 78, 121, 237
- Tourism **is expected to become** a major part of the economy.
- She **is said to have left** early. _(perfect infinitive = прошлое)_
```

### B) There + passive + infinitive / perfect infinitive

```ad-example
title: Example
color: 78, 121, 237
- There **are reported to have been** a record number of accidents this year.
```

### C) It + passive + that…

```ad-example
title: Example
color: 78, 121, 237
- **It is thought that** the new railway will provide employment.
```

Подробный разбор времён: [[english/Rules/Impersonal structures/It's said, it's assumed|It's said / it's assumed]]

## 3. Direct and indirect object

Глаголы с **двумя** объектами (*give, send, offer, show, tell, lend, pay…*) → **два** пассива:

> Michael gave the plane tickets to Jill.

```ad-example
title: Example
color: 78, 121, 237
- **Jill was given** the plane tickets (by Michael). _(косвенное → subject)_
- **The plane tickets were given** to Jill (by Michael). _(прямое → subject)_
```

### Watch out

- Перед местоимением *to/for* иногда опускают: *was left **(to)** her*
- **explain / suggest** — только с **to**; нельзя *I was explained…*:

```ad-example
title: Example
color: 78, 121, 237
- I **was explained** how to drive. 🔴
- How to drive the train **was explained to** me. 🟢
```

## 4. Avoiding the passive

Пассив **обычно не** с continuous perfect/future (*will be being made*, *have been being…*). Вместо этого — готовые фразы:

| Вместо уродливого пассива | Говори |
|---|---|
| will be being made | **will be in progress** |
| will have been being trained | **will have been in training** |
| have been being displayed | **have been on display** |
| had been being considered | **had been under consideration** |
| has been being built | **has been under construction** |

```ad-example
title: Example
color: 78, 121, 237
- The new station **has been under construction** for two years. 🟢
- The new station **has been being built** for two years. 🔴 _(избегают)_
```

### Что редко / не бывает в пассиве

- непереходные: *appear, arrive, die…*
- stative: *have, seem, suit, lack, resemble…*
- *let* (= allow) — не пассив; но phrasal ок: *she **was let off***
- *hear / help / make / see*: active → bare infinitive; passive → **to**-infinitive:

```ad-example
title: Example
color: 78, 121, 237
- We heard Jim **say** he was going. → Jim **was heard to say** he was going.
```

## 5. Causatives

### get / have something done

1. **Заказал / устроил**, чтобы сделали тебе:

```ad-example
title: Example
color: 78, 121, 237
- Did you finally **get your bike fixed**?
- I'm **having my hair cut** tomorrow.
```

2. **Случилось с тобой** (часто плохо, не по желанию):

```ad-example
title: Example
color: 78, 121, 237
- Susie **had her motorbike stolen**.
```

*Get* разговорнее, чем *have*.  
Также: *need / want / would like* + object + V3: *I'd like those cars **washed** by this evening.*  
*get sth done* иногда = **закончить**: *as soon as I've **got the car fixed*** (= finished fixing).

### get somebody to do / have somebody do

Заставить / уговорить кого-то сделать:

```ad-example
title: Example
color: 78, 121, 237
- Did you **get Alex to drive** you all the way to London?
- I'll **have someone check** the engine.
```

| | Форма |
|---|---|
| get | **get** sb **to** do |
| have | **have** sb do _(без to)_ |

### get / have somebody doing

Запустить процесс / довести до состояния «делает»:

```ad-example
title: Example
color: 78, 121, 237
- We'll soon **have your car running** like new.
```

## 6. by / with (агент vs инструмент)

```ad-example
title: Example
color: 78, 121, 237
- get the car looked at **by** a professional. _(кто)_
- The engine is started **with** a special card. _(чем)_
- frightened **of** driving; covered **in** dirt. _(свои предлоги у adj)_
```

## Шпаргалка

| Тема | Формула |
|---|---|
| impersonal | *He is said to…* / *It is said that…* / *There are reported to…* |
| 2 объекта | *Jill was given…* **или** *Tickets were given to Jill* |
| explain/suggest | только *explained **to** me* |
| не continuous passive | *under construction / in progress…* |
| заказать услугу | **get/have** sth **done** |
| заставить человека | **get** sb **to** do / **have** sb do |
| запустить процесс | **get/have** sb **doing** |
| агент | **by**; инструмент | **with** |
