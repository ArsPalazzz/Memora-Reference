
### Zero conditional

**Use**: facts

If + to be, ... to be

##### Example: 
- if the water temperature is 100 degrees, it evaporates




### First conditional

**Use**: real situations in the future

If + to be, ... will / can + V1

##### Example: 
- if you're at school today, you'll probably start working sometime in the 2020's




### Second conditional

**Use**: imaginary situations in the present or in the future

If + V2, ... would / could + to be

##### Example: 
- if  these drawings were painted more realistically, they would look amazing



### Third conditional

**Use**: imaginary situations in the past

If + had V3, ... would have / could have + V3

##### Example: 
- if  she had wanted pictures, she would have told us




### Mixed conditional

**Use**: imaginary situations and results in the past

If + had V3, ... would / could + to be
If + was/were ... , ... would have been

##### Example: 
- if  their school had encouraged unusual ways of seeing the world, lots of adults would be more creative
- If I was taller, I would have played basketball
