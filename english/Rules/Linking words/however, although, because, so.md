# However, although, because, so (+ time connectors)

Связки: **contrast** (*however / although*), **reason** (*because / because of*), **result** (*so*), плюс **время** (*before / after / while / as soon as / when / once*).

![[however although because so.png]]

---

## 1. Contrast — however

**however** ≈ *but*. Обычно в **начале** предложения: после **.** или **;** и **запятая после** *however*:

```ad-example
title: Example
color: 78, 121, 237
- We didn't like the hotel. **However**, we had a good time.
- I would like to have a dog; **however**, my husband is allergic to dogs.
```

---

## 2. Contrast — although

**although** ≈ *despite the fact that* / *but*. В начале или в середине. **Без запятой сразу после** *although*: **although + subject + verb**:

```ad-example
title: Example
color: 78, 121, 237
- **Although** he had a bad leg, he still won the game.
- I passed the exam, **although** I hadn't studied.
```

---

## 3. Reason — because / because of

**because** + subject + verb:

```ad-example
title: Example
color: 78, 121, 237
- We had to cancel the concert **because** it was raining.
- I didn't call you **because** I didn't want to worry you.
```

**because of** + noun:

```ad-example
title: Example
color: 78, 121, 237
- We had to cancel the concert **because of** the rain.
- Many shops had to close **because of** the economic situation.
```

---

## 4. Result — so

Следствие. Обычно в **середине** после **,** :

```ad-example
title: Example
color: 78, 121, 237
- We worked hard all morning, **so** I am very tired now.
- The TV is very expensive, **so** I don't think I'll buy it.
```

---

## 5. Time — before

**before** + noun / -ing **или** **before** + subject + verb:

```ad-example
title: Example
color: 78, 121, 237
- **Before** I have breakfast, I read a few pages.
- **Before** having breakfast, I read a few pages.
- **Before** breakfast, I read a few pages.
```

---

## 6. Time — after

**after** + noun / -ing **или** **after** + subject + verb:

```ad-example
title: Example
color: 78, 121, 237
- I smoke a cigarette **after** dinner / **after** having dinner / **after** I have dinner.
```

Последовательные действия — **then / after that**, не одно *After* в начале:

```ad-example
title: Example
color: 78, 121, 237
- I got up and had a shower. **After**, I made breakfast. 🔴
- I got up and had a shower. **Then/After that**, I made breakfast. 🟢
```

---

## 7. Time — while

**while** + subject + verb — действия **одновременно**:

```ad-example
title: Example
color: 78, 121, 237
- I read the newspaper **while** I was waiting.
```

---

## 8. Time — as soon as / when / once

Схожий смысл; **as soon as** = сразу когда:

```ad-example
title: Example
color: 78, 121, 237
- **As soon as/when/once** I get home, I'll finish my homework.
```

---

## 9. Частые ошибки (time)

После *before / after / as soon as / when / once* о будущем — **present simple**, не *will*:

```ad-example
title: Example
color: 78, 121, 237
- When I **will get** home, I'll call you. 🔴
- When I **get** home, I'll call you. 🟢
```

Запятая, если связка в **начале**; без запятой, если во **второй** части:

```ad-example
title: Example
color: 78, 121, 237
- **Before** I go to bed, I brush my teeth.
- I brush my teeth **before** I go to bed.
```

---

## Шпаргалка

| Связка | Тип | Формула / пунктуация |
|---|---|---|
| **however** | contrast | `.` / `;` + **However**, … |
| **although** | contrast | **although** + S + V (без `,` сразу после) |
| **because** | reason | **because** + S + V |
| **because of** | reason | **because of** + noun |
| **so** | result | …, **so** + S + V |
| **before / after** | time | + noun / -ing / S + V |
| **then / after that** | последовательность | не *After,* в начале |
| **while** | одновременно | **while** + S + V |
| **as soon as / when / once** | время | present (не will) о будущем |
