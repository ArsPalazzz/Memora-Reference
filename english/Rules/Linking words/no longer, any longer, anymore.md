# No longer, any longer, anymore

«Раньше было / происходило, **сейчас нет**». Смысл один, позиция и тип предложения разные. *No longer* чуть формальнее.

![[no longer any longer anymore.png]]

```ad-example
title: Example
color: 78, 121, 237
- She **no longer** works here.
- She doesn't work here **any longer**.
- She doesn't work here **anymore**.
```

---

## 1. No longer

Только в **положительных** предложениях (само делает смысл отрицательным). Позиция — **mid**:

**Перед** смысловым глаголом:

```ad-example
title: Example
color: 78, 121, 237
- I **no longer** eat meat.
- He **no longer** plays football.
```

**После** *be*:

```ad-example
title: Example
color: 78, 121, 237
- We **are no longer** friends.
- He **is no longer** a footballer.
```

**После** modal / auxiliary:

```ad-example
title: Example
color: 78, 121, 237
- Jim **will no longer** attend his lessons.
- We **can no longer** bring phones to school.
```

В вопросах — после подлежащего:

```ad-example
title: Example
color: 78, 121, 237
- Do you **no longer** want to play?
- Is he **no longer** happy?
```

---

## 2. Any longer / anymore

Только в **отрицаниях** и **вопросах**; всегда в **конце**. Взаимозаменяемы (*any longer* чуть формальнее):

```ad-example
title: Example
color: 78, 121, 237
- We don't live there **any longer/anymore**.
- We aren't friends **any longer/anymore**.
- Why don't you visit us **any longer/anymore**?
```

---

## 3. Anymore vs any more

| | Значение | Пример |
|---|---|---|
| **anymore** (одно слово) | время: «больше не» | I don't eat chicken **anymore**. |
| **any more** (два слова) | количество: «ещё» | Do you want **any more** chicken? |

```ad-example
title: Example
color: 78, 121, 237
- I don't eat chicken **anymore**. 🟢 (время)
- I don't eat chicken **any more**. 🔴 (в значении «больше не»)
- Do you want **any more** chicken? 🟢 (количество)
- Do you want **anymore** chicken? 🔴
```

---

## Шпаргалка

| Фраза | Предложение | Позиция |
|---|---|---|
| **no longer** | + (само «отрицает») | mid (перед V; после be/modal) |
| **any longer / anymore** | − / ? | end |
| **anymore** | время | I don't… **anymore** |
| **any more** | количество | **any more** candy? |
