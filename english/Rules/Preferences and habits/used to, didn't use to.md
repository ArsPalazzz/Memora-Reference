# Used to / didn’t use to

**used to** — прошлые привычки и состояния, которых **сейчас нет**.  
Для **настоящих** привычек — present simple + **usually / normally** (не *use to*).

![[used to didnt use to.png]]

См. также: [[english/Rules/Preferences and habits/used to, would, be used to, get used to|used to / would / be used to / get used to]]

---

## 1. Past habits

Повторяющиеся действия в прошлом, которые больше не происходят:

```ad-example
title: Example
color: 78, 121, 237
- I **used to play** chess every day, but now I don't play very often.
- When the economy was better, we **used to eat** out every week.
```

---

## 2. Past states

С *be, have, like…* — то, что **было правдой**, а сейчас нет:

```ad-example
title: Example
color: 78, 121, 237
- She **used to be** very shy when she was a child.
- I **used to like** her music, but now I hate it.
```

---

## 3. Form: didn’t use to / did … use to?

В − / ? — **did/didn’t + use to** (без **-d** у *use*):

```ad-example
title: Example
color: 78, 121, 237
- He **didn't use to** travel a lot.
- '**Did** he **use to** live here?' 'Yes, he **did**.'
```

Отрицание также с **never**:

```ad-example
title: Example
color: 78, 121, 237
- We **never used to** argue.
```

---

## 4. Past simple vs used to

Past simple + *always / usually / often…* ≈ *used to* для привычек:

```ad-example
title: Example
color: 78, 121, 237
- I **always met** her at the bar down the street. _(≈ used to meet)_
- I **usually had** a big salad for dinner. _(≈ used to have)_
```

Один раз / есть **когда** (*last week, last Sunday…*) — только **past simple**, не *used to*:

```ad-example
title: Example
color: 78, 121, 237
- Last week, I **used to meet** her at the bar. 🔴
- Last week, I **met** her at the bar. 🟢
- I **used to have** a big salad for dinner last Sunday. 🔴
- I **had** a big salad for dinner last Sunday. 🟢
```

---

## 5. Usually (present) ≠ used to (past)

**used to** только про прошлое. Сейчас — **usually / normally** + present simple:

```ad-example
title: Example
color: 78, 121, 237
- I **use to get** up very early at weekends. 🔴
- I **usually get** up very early at weekends. 🟢
- We **don't use to** play on Sunday. 🔴
- We **don't usually** play on Sunday. 🟢
```

---

## Шпаргалка

| | Форма | Когда |
|---|---|---|
| **+** | **used to** + V | прошлые привычки / состояния |
| **−** | **didn't use to** + V / **never used to** | |
| **?** | **Did** … **use to** + V? | Yes/No, … did/didn't |
| привычка сейчас | **usually** + present | не *use to* |
| один раз / с датой | **past simple** | не *used to* |
