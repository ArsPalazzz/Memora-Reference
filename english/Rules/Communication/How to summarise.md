# How to summarise

SpeakOut 5C — **How to summarise**: пересказать суть (проверить понимание) или дать ключевые пункты концепции / обсуждения.

![[How to summarise 5C.png]]

**Исходная страница:** [[english/Rules/Course notes/SpeakOut/How to summarise 5C|SpeakOut 5C]]

---

## Общая идея

Summarising = **перефразировать** то, что уже сказали:

| Задача | Смысл |
|---|---|
| **Checking understanding** | переспрашиваешь: «я правильно понял?» — **не уверен**, ждёшь подтверждения |
| **Summarising key points** | резюмируешь: «вот суть» — **уверен**, просто подводишь итог |

```ad-example
title: Example
color: 78, 121, 237
- **So what you mean is that** you tried it before and it worked to a degree. _(checking)_
- **So what you're saying is that** you don't think this idea will work. _(checking)_
- **Basically**, a petition involves getting people's signatures. _(key points)_
- **In a nutshell**, we've got two very different ideas to choose between. _(key points)_
```

---

## 1. Checking understanding

Переспрашиваешь собеседника: правильно ли понял. **Не уверен** — хочешь подтверждения.

### So what you're saying is (that) …

= «То есть ты говоришь, что…»

**Когда:** перефразируешь **слова** собеседника, чтобы проверить понимание.  
**Тон:** нейтральный, вежливый.

```ad-example
title: Example
color: 78, 121, 237
- **So what you're saying is that** we should postpone the meeting until next week?
- **So what you're saying is that** you don't agree with the new policy?
```

### So what you mean is (that) …

= «То есть ты имеешь в виду, что…»

**Когда:** проверяешь **смысл / намёк**, а не буквальные слова — собеседник сказал непрямо.  
**Тон:** чуть менее формальный, чем *what you're saying*.

```ad-example
title: Example
color: 78, 121, 237
- **So what you mean is that** you don't want to go, but you don't want to say it directly?
- **So what you mean is that** the project is too expensive for us?
```

### To put it another way, …

= «Другими словами / если сказать иначе…»

**Когда:** переформулируешь мысль собеседника **своими** словами (проверка) **или** свою мысль — чтобы было понятнее.  
**Тон:** нейтральный, чуть формальнее.

```ad-example
title: Example
color: 78, 121, 237
- **To put it another way**, you think we should focus on quality rather than quantity?
- **To put it another way**, we need to cut costs by 20%.
```

### In other words, …

= «Другими словами / иными словами…»

**Когда:** самый **универсальный** вариант — упростить / прояснить мысль.  
**Тон:** нейтральный.

```ad-example
title: Example
color: 78, 121, 237
- **In other words**, you're not interested in this job at all?
- **In other words**, we have to finish this by Friday or we lose the contract.
```

## 2. Summarising key points

Подводишь итог разговора или главные мысли. Здесь ты **уверен**, что понял, — просто резюмируешь.

### In brief, …

= «Вкратце…»

**Когда:** коротко резюмировать **без деталей**.  
**Тон:** нейтральный, немного формальный.

```ad-example
title: Example
color: 78, 121, 237
- **In brief**, we agreed to launch the product next month.
- **In brief**, the situation is getting worse.
```

### In a nutshell, …

= «В двух словах / если коротко…»

**Когда:** разговорно сжать суть («суть в том, что…»).  
**Тон:** неформальный, разговорный.

```ad-example
title: Example
color: 78, 121, 237
- **In a nutshell**, we're broke.
- **In a nutshell**, the project failed because of poor planning.
```

### Basically, …

= «В общем / по сути / короче…»

**Когда:** сказать **самое главное**, опустив детали.  
**Тон:** очень разговорный.

```ad-example
title: Example
color: 78, 121, 237
- **Basically**, we need more time and more money.
- **Basically**, he quit because he hated his boss.
```

### To recap, …

= «Напомним / резюмируя…» (кратко повторить)

**Когда:** повторить уже обсуждённое, чтобы **освежить память** — презентации, конец длинного обсуждения.  
**Тон:** формальный, деловой.

```ad-example
title: Example
color: 78, 121, 237
- **To recap**, we have three main tasks: design, testing, and launch.
- **To recap**, we agreed to meet again next week.
```

### So to summarise, …

= «Итак, подводя итог…»

**Когда:** **официально** закрыть выступление / эссе / презентацию итогом.  
**Тон:** формальный, нейтральный.

```ad-example
title: Example
color: 78, 121, 237
- **So to summarise**, we need to invest more in renewable energy.
- **So to summarise**, the main problem is lack of communication.
```

### So what we're saying is (that) …

= «Итак, мы говорим о том, что…»

**Когда:** итог **от лица группы** («мы») — команда, собрание.  
**Тон:** нейтральный, деловой.

```ad-example
title: Example
color: 78, 121, 237
- **So what we're saying is that** we need to change our strategy.
- **So what we're saying is that** the current system doesn't work.
```

## 3. Позиция в предложении

В разговоре *basically, in other words, in a nutshell, to put it another way* — часто в **начале** или в **конце**:

```ad-example
title: Example
color: 78, 121, 237
- **Basically**, it's something you use to filter unclean water.
- It's something you use to filter unclean water, **basically**.
- **To put it another way**, it's not something you want to use.
- It's not something you want to use, **to put it another way**.
```

## Шпаргалка

| Фраза | Когда | Тон |
|---|---|---|
| **So what you're saying is…** | пересказ слов → «правильно понял?» | нейтральный |
| **So what you mean is…** | смысл / намёк, не буквально | чуть informal |
| **To put it another way…** | переформулировать (свою или чужую) | чуть formal |
| **In other words…** | универсально упростить | нейтральный |
| **In brief…** | кратко без деталей | чуть formal |
| **In a nutshell…** | суть в двух словах | informal |
| **Basically…** | главное без деталей | очень informal |
| **To recap…** | повторить уже сказанное | formal / деловой |
| **So to summarise…** | официальный итог | formal |
| **So what we're saying is…** | итог от «мы» | деловой |
