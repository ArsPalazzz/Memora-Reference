# Comparing and evaluating ideas

SpeakOut 2C — **How to compare and evaluate ideas**: сравнить варианты (большая / маленькая / нулевая разница) и оценить, **насколько идея полезна**.

![[Compare and evaluate ideas 2C.png]]

**Исходная страница:** [[english/Rules/Course notes/SpeakOut/Compare and evaluate ideas 2C|SpeakOut 2C]]

---

## Общая идея

При сравнении фразы показывают:

| Разница | Смысл |
|---|---|
| **big** | сильно отличается |
| **small** | почти одинаково, чуть лучше/хуже |
| **no difference** | на одном уровне |

Плюс отдельно — **evaluating**: идея работает / не работает.

---

## 1. Comparing — большая разница

| Регистр | Фразы |
|---|---|
| **Informal** | **way / miles / loads** more … than … |
| **Neutral** | **much / a lot / far** (more) … than …; **nowhere near as** … as; **nothing like as** … as |
| **Semi-formal / formal** | **considerably / significantly / infinitely** (more) … than … |

> It's **much easier** to give a bonus **than** create a whole new pay system.  
> A minimum salary scheme would take **way** longer to set up.  
> A four-day week is **infinitely** better than a five-day week.  
> This option is **nowhere near as** practical **as** the first one.  
> It's **nothing like as** cheap **as** we hoped.

---

## 2. Comparing — маленькая разница

| Регистр | Фразы |
|---|---|
| **Neutral** | **a little / slightly / a bit** (more) … than …; **almost as** … as |
| **Semi-formal / formal** | **marginally** (more) … than … |

> I think option 1 is **marginally more** interesting than option 2.  
> It's **slightly** cheaper **than** the other plan.  
> This is **almost as** good **as** the original.

---

## 3. Comparing — без разницы

| Фраза | Пример |
|---|---|
| **just as** … (as) | It's **just as** important **as** pay. |
| **every bit as** … (as) | This computer is **every bit as** useless **as** the last one! |
| **equally** … (as) | Both options are **equally** risky. |

*every bit as* ≈ *just as*, но сильнее («ничуть не меньше»).

---

## 4. Evaluating — эффективно

| Фраза | После |
|---|---|
| be **valuable to** | someone |
| be **invaluable to / for** | someone |
| be **effective for** | someone |
| be **useful for** | someone |
| be **effective in** | **doing** something |
| be **useful in** | **doing** something |

> The mentor programme is **invaluable for** people who need some support.  
> It would be **effective in** helping junior members of staff.  
> It'll be **useful in** making people feel appreciated.  
> This scheme is **valuable to** new hires.

**invaluable** = очень ценный (не «неценный»).

---

## 5. Evaluating — неэффективно

| Фраза | После |
|---|---|
| be **useless for** | someone |
| be **useless at** | **doing** something |
| be **a waste of** time / energy | (for someone) |
| be **ineffective for** | someone |
| be **ineffective in** | **doing** something |
| be **unhelpful for** | someone |

> It's **a waste of time** and effort **for** the company.  
> The scheme would be **ineffective in** achieving what it wants.  
> This tool is **useless at** tracking bugs.  
> The feedback was **unhelpful for** the team.

### for someone vs in / at doing

| | Кому / чему | Действие |
|---|---|---|
| **for** | people, the company… | — |
| **in / at** + **-ing** | — | helping, achieving, tracking… |

---

## Шпаргалка

- Большая разница: *way / much / far / infinitely … than*; *nowhere near as … as*
- Маленькая: *a bit / slightly / marginally … than*; *almost as … as*
- Одинаково: *just as / every bit as / equally*
- Работает: *valuable / invaluable / effective / useful* + **for** / **in -ing**
- Не работает: *useless / ineffective / unhelpful / a waste of time* + **for** / **in/at -ing**
