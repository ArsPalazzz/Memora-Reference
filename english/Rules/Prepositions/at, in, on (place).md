# at / in / on (place)

Предлоги места: **at** — точка / событие / «у», **in** — внутри / территория, **on** — поверхность / транспорт / медиа.

## 1. at

### At a point

**at** — точка **рядом** с чем-то (не «внутри»):

```ad-example
title: Example
color: 78, 121, 237
- Can you see that car **at** the traffic light?
- Who is that man **at** the door?
```

### at the top / bottom / end of

```ad-example
title: Example
color: 78, 121, 237
- She is **at the top of** the stairs.
- Please sign **at the bottom of** the page.
- The new café is **at the end of** the street.
```

### Group activities

Мероприятия, события (party, concert, cinema…):

```ad-example
title: Example
color: 78, 121, 237
- We were **at** the cinema.
- I didn't see you **at** Jackie's party.
- We met **at** a concert.
```

### school / university / college

Обычно **at** (без *the*):

```ad-example
title: Example
color: 78, 121, 237
- He is **at school** every morning until 12.
- I'm studying **at** Oxford University.
```

### at home / at work

Без **the**:

```ad-example
title: Example
color: 78, 121, 237
- She's **at home**. 🟢
- She's **at the home**. 🔴
- I'll be **at work** all morning. 🟢
- I'll be **at the work** all morning. 🔴
```

### Shops, cafés, etc.

```ad-example
title: Example
color: 78, 121, 237
- I'm **at** the bakery.
- If you are **at** the chemist's, can you buy some aspirin?
```

## 2. in

### In a 3D space

Внутри трёхмерного пространства:

```ad-example
title: Example
color: 78, 121, 237
- The book is **in** the bag.
- She is waiting **in** the classroom.
```

### Territory / areas with limits

Страны, города, регионы, континенты:

```ad-example
title: Example
color: 78, 121, 237
- We are **in** France.
- I love the houses **in** the Alps.
```

### Car / van

```ad-example
title: Example
color: 78, 121, 237
- They are **in** the car.
```

### Water

```ad-example
title: Example
color: 78, 121, 237
- The kids have fun **in** the swimming pool.
```

### Printed material

В книге, картинке, газете:

```ad-example
title: Example
color: 78, 121, 237
- Who's that woman **in** the picture?
- Does it say anything about the concert **in** the newspaper?
```

## 3. on

### On a surface

На поверхности:

```ad-example
title: Example
color: 78, 121, 237
- The book is **on** the table.
```

### Floors

```ad-example
title: Example
color: 78, 121, 237
- The office is **on** the third floor.
```

### on the right / left

```ad-example
title: Example
color: 78, 121, 237
- The office is on the third floor **on the left**.
```

### Public transport

Автобус, поезд, самолёт — **on** (не *in*):

```ad-example
title: Example
color: 78, 121, 237
- She's **on** the bus right now.
```

### Media

TV, radio, internet, website:

```ad-example
title: Example
color: 78, 121, 237
- I saw it **on** TV last night.
- I learned it **on** the internet.
```

## Шпаргалка

| Предлог | Когда | Примеры |
|---|---|---|
| **at** | точка рядом; top/bottom/end; события; school/work/home; магазины | at the door, at a party, at home, at the bakery |
| **in** | внутри 3D; территория; машина; вода; текст/картинка | in the bag, in France, in the car, in the picture |
| **on** | поверхность; этаж; right/left; общественный транспорт; медиа | on the table, on the third floor, on the bus, on TV |
