# Memora Reference

Справочник по языкам: правила, разборы, слова и заметки с занятий.  
Повторение слов — в **Memora**.

---

## Языки

| Язык | Описание |
|---|---|
| [[english/README\|English]] | Грамматика, примеры, словарь, план занятий |

---

## Структура

```
english/
├── Rules/       — грамматические правила
├── Examples/    — разборы предложений
├── Words/       — слова и выражения
├── Study plan/  — план занятий
└── Inbox/       — новое, что ещё не разобрано
```

Новое попадает в `Inbox/` → после разбора — в `Rules/` или `Words/`.  
Предложения с вопросом «почему так?» → в `Examples/`.
